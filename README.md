# Игра 51

Карточная игра «51» — рамми по домашним правилам: 108 карт, по 14 на руку, первая выкладка от 51 очка, партия из 9 раздач. Сейчас это одиночная игра против ботов (от 1 до 5 соперников, три уровня силы), на русском и английском.

Игра — один самодостаточный файл `index.html`. Он открывается в обычном браузере и внутри Telegram как мини-приложение.

## Как устроен код

| Файл | Что в нём |
| --- | --- |
| `src/engine.js` | Правила: раздача, комбинации, открытие, джокеры, подсчёт. Без интерфейса, работает и в Node |
| `src/bots.js` | Боты: поиск комбинаций, решение об открытии, сброс; три уровня силы |
| `src/hint.js` | Подсказка игроку в его ход |
| `src/i18n.js` | Все строки на русском и английском |
| `src/ui.js` | Стол, рука, счёт, окна |
| `src/telegram.js` | Запуск внутри Telegram; в обычном браузере ничего не делает |
| `src/template.html` | Разметка и стили; сюда сборка подставляет скрипты |
| `build.js` | Собирает `index.html` из `src/` |
| `test/` | Тесты правил и прогон партий ботами |

`index.html` в корне — результат сборки. Руками его не правят: меняют файлы в `src/` и пересобирают.

## Сборка и тесты

Нужен только Node.js, зависимостей нет.

```
npm run build   # собрать index.html
npm test        # тесты правил и 150 партий ботов на всех уровнях
```

Перед каждой выкладкой: тесты, затем сборка, затем коммит вместе с новым `index.html`.

## Выкладка

Страницу раздаёт GitHub Pages из ветки `main`, из корня репозитория. После отправки изменений в `main` сайт обновляется сам за минуту-две.

## Telegram

1. В @BotFather создать бота командой `/newbot`.
2. Командой `/newapp` (или `/setmenubutton`) привязать к боту адрес страницы на GitHub Pages.

Внутри Telegram игра разворачивается на всю высоту, отключает закрытие жестом «потянуть вниз», берёт имя и язык игрока из его профиля. Токен бота для этого не нужен и в репозитории храниться не должен.

## Что дальше

Сетевая игра за общим столом: для неё нужен сервер с постоянно работающим процессом. Движок правил от интерфейса отделён, поэтому на сервере будет работать тот же `src/engine.js`.
